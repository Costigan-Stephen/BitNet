Training

          

            This launches BitNet-native continued training (full checkpoint fine-tuning, not PEFT LoRA adapters).
          

          

            Use a BitNet-compatible checkpoint. Default uses Falcon-E prequantized weights. After training, export/convert to your runtime format (for example GGUF) if needed.
          

          
          
          
          
          
          
          
          
          

            JSON/JSONL/CSV are used directly. Documents (.txt/.md/.rst/.log/.doc/.docx/.pdf) are auto-converted into JSONL training rows.
